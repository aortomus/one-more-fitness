One More v1.2

Update your existing GitHub Pages repository by uploading the seven files from this ZIP to the repository root, then commit changes. Keep the existing repository and URL.

New measurement types: Sets + Reps, Sets + Seconds, and Sets + Reps + Weight (formerly Reps + Weight). Each set has an independent entry, up to 50 sets per exercise. Progress charts support total reps/seconds and number of sets. Existing single-value and weighted-set records remain supported.

Before updating, use Settings > Download backup if you have data. Workout history stays in the device browser, not GitHub. Once published, refresh while online or close/reopen the installed app to load v1.2.
