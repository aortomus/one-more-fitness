ONE MORE - FITNESS TRACKER

QUICK TEST
Open index.html in a browser on a computer. The app records workouts in that browser's local storage.

INSTALL ON ANDROID (RECOMMENDED)
1. Create a free GitHub account if needed.
2. Create a new PUBLIC repository (for example, one-more-fitness). The app code will be public, but workout data stays on your device and is NOT uploaded to the repository.
3. Upload ALL SIX files from this folder to the repository root: index.html, sw.js, manifest.webmanifest, icon.svg, icon-192.png, icon-512.png.
4. In repository Settings > Pages, select Deploy from a branch, main, /(root), and Save.
5. Wait for the Pages link to appear. Open it in Chrome on Android.
6. From Chrome's menu, choose Install app or Add to Home screen.

IMPORTANT
- Data is saved locally per browser/device and origin, not synchronized.
- Use Settings > Download backup regularly. Restore backup when switching phones or browsers.
- Clearing site data or using private browsing may lose records.
- A public GitHub repository publishes only the app's code. Do not upload your backup file.
- Install/offline behavior requires HTTPS hosting (such as GitHub Pages) or localhost.
- Editing the app later requires updating the hosted files and reloading; cache updates may need an app restart.
- This is a simple tracker, not medical guidance.
